# Welcome to My Ls

This project was originally started on another plateform over half a month ago.
The aim of this repo is to update this old project to the specifications and refine it.

## Task
Remake a part of ls.
Synopsis : my_ls [-at] [file ...]

## Description
The imposed functions made it clear what direction to go and comparing my_ls to ls allowed to refine the more subtle aspects

## Installation
Use Makefile to compile my_ls.c with the command 'make'.

## Usage
Execute the compiled file the same way you'd execute the ls command.
